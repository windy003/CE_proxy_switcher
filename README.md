# Proxy Switcher - Chrome 代理切换扩展

一个简单易用的 Chrome 代理切换扩展，类似 Proxy SwitchyOmega，支持快捷键快速切换代理配置。

## 功能特点

- 支持多个代理配置管理
- 支持 HTTP、HTTPS、SOCKS4、SOCKS5 代理类型
- **按网站分流**：手动指定哪些网站走代理、哪些网站直连
- **当前网站一键设置**：打开扩展自动识别当前网站，一键设为走代理或直连
- 快捷键快速切换代理开关（Alt+Shift+O）
- 快捷键切换下一个配置（Alt+Shift+N）
- 简洁直观的用户界面
- 实时显示当前代理状态

## 安装方法

1. 下载或克隆此项目到本地
2. 打开 Chrome 浏览器，进入扩展管理页面 `chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 `proxy-switcher` 文件夹
6. **重要：设置快捷键**
   - 打开 `chrome://extensions/shortcuts`
   - 找到 "Proxy Switcher"
   - 点击快捷键输入框，按下 `Alt+Shift+O`（或你喜欢的组合键）
   - 确保快捷键已保存

```bash
convert -size 128x128 xc:#3b82f6 icons/icon128.png
```

## 使用说明

### 添加代理配置

1. 点击浏览器工具栏的扩展图标
2. 点击"+ 添加配置"按钮
3. 填写配置信息：
   - 配置名称：例如"公司代理"、"开发环境"
   - 代理类型：HTTP/HTTPS/SOCKS4/SOCKS5
   - 服务器地址：例如 127.0.0.1
   - 端口：例如 8080
4. 点击"保存"

### 使用代理

1. 在配置列表中点击 ✓ 按钮启用对应的代理配置
2. 或者点击"启用代理"按钮使用当前选中的配置
3. 点击"关闭代理"按钮停用代理

### 按网站分流（网站规则）

1. 打开扩展面板，点击右上角"网站规则"（或按 `R`）
2. 在"添加规则"中输入网站域名，选择"走代理"或"直连"，点击"添加"（或按 `Enter`）
3. 规则从上到下依次匹配，第一条命中的规则生效
4. 点击规则的标签可以在"走代理 / 直连"之间切换，点击 `×` 删除规则
5. 通过"未匹配的网站"设置没有命中任何规则时的默认行为
6. 规则在启用任意代理配置后生效，修改规则会立即刷新代理设置

规则写法示例：

- `example.com`：匹配 example.com 及其所有子域名
- `*.google.com`：匹配 google.com 及其所有子域名
- `*google*`：使用 `*` 通配符匹配域名
- `https://example.com/news`：按 URL 前缀匹配
- `localhost`、`127.0.0.1` 等本地地址始终直连

### 当前网站快捷设置

打开扩展面板后，顶部会显示当前标签页的网站：

1. 高亮状态表示该网站当前实际走代理还是直连（按规则优先、未命中则跟随默认）
2. 点击「走代理」或「直连」，立即为当前网站添加一条专属规则，并插到规则列表最前面，优先于宽泛规则
3. 如果当前网站已有专属规则，会显示「跟随默认」按钮，点击可删除该规则
4. `www.example.com` 会自动按 `example.com` 设置，同时覆盖其子域名
5. 本地地址（localhost、127.0.0.1、无点主机名等）始终直连，按钮不可用

注意：代理未启用时，规则会先保存，启用代理后生效。

### 常见问题

**启用代理后无法访问外网**

1. 打开「网站规则」，检查「未匹配的网站」是否为「走代理」
2. 检查规则列表中是否有目标网站的「直连」规则
3. 如果改乱了，点击「清空规则并恢复默认」，会清空所有规则并把未匹配网站恢复为「走代理」

**按网站分流不生效**

如果当前 Chrome 拒绝 PAC 脚本，扩展会自动回退为全局代理，并弹出提示；此时所有网站都会走代理，规则暂不生效。可在扩展的 Service Worker 控制台查看具体错误。

### 快捷键

**全局快捷键（任何页面都能用）：**
- `Alt+Shift+O`：打开代理切换面板

**面板内快捷键：**
- `↑↓`：上下选择配置
- `Enter`：应用选中的配置
- `E`：编辑选中的配置
- `D`：删除选中的配置
- `N`：新建配置
- `R`：打开网站规则
- `Esc`：关闭面板 / 返回上一级

**注意：** 全局快捷键需要在 `chrome://extensions/shortcuts` 中手动设置才能生效。

## 技术说明

- 使用 Chrome Extension Manifest V3
- 使用 Chrome Proxy API 管理代理设置
- 使用 Chrome Storage API 保存配置
- 使用 Chrome Commands API 实现快捷键

## 注意事项

- 本扩展仅在 Chrome 浏览器中可用
- 需要"代理"权限才能修改浏览器代理设置
- 代理配置仅在当前浏览器会话中有效
- 建议在公司网络或开发环境中使用
